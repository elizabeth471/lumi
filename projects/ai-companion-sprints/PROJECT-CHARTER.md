# AI COMPANION TIME-BOUND SPRINTS — Project Charter

**Project Name:** AI Companion Sprints (Working title: "Sprint AI" or "4-Week Companion")

**Status:** Active Development

**Owner:** Elizabeth

**Launch Target:** Week 3 (soft launch with 20-50 customers)

---

## PROJECT MISSION

Build and launch a subscription service where customers purchase 4-week time-bound "sprints" with personalized AI companions. Each sprint is goal-focused, time-limited, and designed to provide emotional support and practical help on specific objectives (flirting, motivation, creative work, etc.).

**Core Value Proposition:**
- Personalized AI companion for 4 weeks on YOUR specific goal
- Time-bound (clear endpoint reduces emotional dependency)
- Affordable ($9.99/sprint, higher perceived value than monthly subscription)
- Built on Claude API (smarter than competitors)
- Recurring revenue through chained sprints

---

## SUCCESS CRITERIA (Phase 1)

- [ ] Product documented and fully specified
- [ ] MVP launched (Alex + Casey companions, email delivery)
- [ ] 50+ customers in first 2 weeks
- [ ] Unit economics validated ($9.99 price, API costs, margin)
- [ ] Customer feedback collected (retention, satisfaction)
- [ ] Churn rate measured (expected: end-of-sprint, not mid-sprint)
- [ ] Upsell mechanism working (customers purchasing new sprints)
- [ ] Operations manual created (how to create/manage companions)

---

## PROJECT SCOPE (Phase 1)

**In Scope:**
- 2 initial companion types (Alex + Casey)
- Email-based delivery
- Stripe payment integration
- Simple landing page
- Customer onboarding flow
- Operations/quality control process
- Financial modeling + sustainability plan
- Risk mitigation documentation
- Tech stack decisions + API model requirements

**Out of Scope (Phase 2+):**
- Mobile app
- Slack/Discord integration
- Advanced analytics
- Multiple languages
- Marketplace of companions
- Team/collaborative sprints
