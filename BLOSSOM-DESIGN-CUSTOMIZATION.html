How to Change Blossom's Design

Quick Start (30 seconds)

  1. On your Mac, open: ~/lumi/blossom-companion/config.json
  2. Find the "colors" section
  3. Change a color hex code (e.g., "primary": "#FF0000")
  4. Save the file
  5. Restart Blossom Companion
  6. See the change immediately ✓

What You Can Change (No Code Needed)

Colors

All colors in one place. Use any hex code.

"colors": { "primary": "#5a8a50", // Main color "accent": "#8fbc8f", // Highlights "background": "#f5f1e8", // Background "text": "#2c3e2c", // Text color "thinking": "#e8d4b8", // Thinking state "success": "#6ba85e", // Success color "error": "#c85a54" // Error color }

Animation Speed

Make animations faster or slower (0.5 = slow, 2.0 = fast).

"animation": { "speed": 1.5 // 0.5 to 2.0 }

Messages

Change what Blossom says in each state.

"messages": { "idle": "I'm ready to work", "thinking": "Analyzing...", "processing": "Building...", "speaking": "Here's what I found...", "celebrating": "Done! 🎉" }

Appearance Settings

Window behavior and visual style.

"appearance": { "alwaysOnTop": true, // Stays on top "opacity": 0.95, // 0.5 = transparent, 1.0 = solid "position": "right", // right or left side "theme": "light" // or "dark" }
💡 Live Updates: Edit config.json, save, restart the app. Changes apply immediately. No recompiling, no waiting.

Design Philosophy

Blossom is designed to be:

  • Warm & Approachable — A cactus that's friendly, not prickly
  • Clear & Purposeful — Every animation has meaning (idle, thinking, done)
  • Respectful of Space — Stays on top but never intrusive
  • Customizable — Your brand, your colors, your style
  • Accessible — Works in dark mode, respects reduce-motion preference
  • Lightweight — Pure SVG + CSS, no heavy assets

When You're Back on Your Mac

The real experience:

cd ~/lumi/blossom-companion npm run dev

You'll see:

  • Window opens (350×500) with animated Blossom character
  • Smooth CSS animations (idle bobbing, thinking pulse, celebrating jump)
  • Thinking process visible in real-time
  • Settings panel (customize while running)
  • Window stays on top while you work

Then, to customize: Edit config.json, save, restart. Your changes take effect immediately.
