How It Works

The Blossom Companion is an Electron app that runs on your Mac. It communicates with Blossom OS via IPC (Inter-Process Communication), receiving state updates and animation triggers.

Data Flow:
Blossom OS (main platform) ↓ (sends state update) Electron Main Process (main.js) ↓ (IPC message) Renderer Process (renderer.js) ↓ (updates state machine) Character Animation (CSS + SVG) ↓ (visual feedback) You see Blossom animated

When you're building something or running a task, Blossom OS tells the Companion app what state to enter. The app then animates the character and shows the thinking process.

Configuration Example

The config.json file controls everything. Want to change colors, speed, or messages? Just edit JSON, no code rebuild needed.

{ "colors": { "primary": "#5a8a50", // Main cactus green "accent": "#8fbc8f", // Lighter green "thinking": "#e8d4b8" // Thinking state color }, "animation": { "speed": 1.5, // 0.5 = slow, 2.0 = fast "showThinkingProcess": true }, "appearance": { "alwaysOnTop": true, "opacity": 0.95 } }
